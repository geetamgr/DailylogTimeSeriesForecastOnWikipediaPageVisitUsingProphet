# Prophet Time Series Forecasting

A hands-on practice repo following the official Facebook Prophet quick start guide.

## What's covered
- Loading and preparing time series data
- Fitting a Prophet model
- Generating and visualizing forecasts
- Exploring trend and seasonality components

## Tech Stack
- Python
- Prophet (by Meta)
- Pandas
- Matplotlib
